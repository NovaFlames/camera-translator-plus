# Camera Translator Plus

A web application for translating text captured with a camera. The project is built with React, TypeScript, and Vite, with Capacitor support for Android.

## Features

- Camera-oriented translation experience
- Responsive web interface
- Android support through Capacitor

## Tech stack

- [React](https://react.dev/) 18
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)
- [Capacitor](https://capacitorjs.com/)

## Getting started

### Prerequisites

- [Node.js](https://nodejs.org/) and npm
- Git

### Installation

```bash
git clone https://github.com/NovaFlames/camera-translator-plus.git
cd camera-translator-plus
npm ci
```

### Run locally

```bash
npm run dev
```

Vite will print the local URL in the terminal.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run build:dev` | Create a development-mode build |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
| `npm test` | Run the test suite once |
| `npm run test:watch` | Run tests in watch mode |

## Android

This project includes Capacitor Android support. After configuring the required native project and platform settings, use the [Capacitor Android documentation](https://capacitorjs.com/docs/android) to build and run the Android app.
